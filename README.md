# Мой день — планировщик дня

Лёгкое PWA-приложение: задачи, тайм-блоки, привычки, неделя и итоги.
Работает на Mac и iPhone, офлайн, синхронизируется через Supabase.

Без сборки, без зависимостей, без фреймворков — только HTML, CSS и ванильный JS.
Ставится на GitHub Pages как есть.

---

## Что умеет

| Раздел | Возможности |
|---|---|
| **День** | задачи с приоритетом и оценкой времени, тайм-блоки в сетке дня, конфликты слотов, привычки на сегодня, итоги вечера |
| **Привычки** | недельная сетка Пн–Вс, отметки по дням, прогресс за неделю, стрики |
| **Неделя** | 7 карточек с кольцами прогресса, быстрый переход к дню |
| **Итоги** | серия дней, лучшая серия, график за 14 дней, процент выполнения, заметка о дне |
| **Ещё** | тема (тёмная/светлая/системная), напоминания, синхронизация, экспорт JSON и .ics |

**Офлайн.** Всё лежит в `localStorage`, интерфейс кешируется service worker'ом.
Без сети приложение открывается и работает, изменения уходят в облако позже.

**Синхронизация.** Каждый день — отдельная запись, слияние по `updatedAt`.
Конфликт затрагивает только один день, а не всю базу.

## Supabase: синхронизация между Mac и iPhone

1. Создай бесплатный проект на [supabase.com](https://supabase.com).
2. SQL Editor → New query → вставь содержимое `supabase.sql` → Run.
   Появится таблица `days` с открытой политикой для `anon`.
3. Settings → API → скопируй **Project URL** и **anon public** ключ.
4. В приложении: «Ещё» → «Синхронизация» → вставь URL и ключ → «Подключить».
5. Повтори п. 4 на втором устройстве. Поле **Пространство** должно совпадать
   (по умолчанию `personal`).

Готово: точка в приложении станет зелёной, дни начнут сходиться.

> Ключ хранится в `localStorage` браузера, а не в коде. Но `anon`-ключ публичен
> по своей природе: политика в `supabase.sql` открывает таблицу всем, кто знает
> URL и ключ. Для личного планировщика это приемлемо; для настоящей приватности
> включи Supabase Auth (magic link) и замени политику на `auth.uid() = user_id`.

## Напоминания: честно о пределах iOS

Уведомления приходят, пока приложение открыто (на Mac и на iPhone).
Полноценные push-уведомления при закрытом приложении требуют серверной части
(VAPID + APNs) — в текущей версии их нет.

Рабочая альтернатива, которая есть уже сейчас:
«Ещё» → «Календарь» → скачать `.ics` на завтра → открыть в Календаре.
События встанут с будильником за 10 минут — это системные уведомления, они работают всегда.

## Доступность

Прошёл аудит по WCAG 2.2 AA (код + рантайм-замеры в WebKit). Что сделано:

- контраст текста ≥ 4.5:1 в обеих темах (токены `--ink-faint`, `--control-line` пересчитаны),
  границы инпутов ≥ 3:1, белый текст на фиолетовых кнопках ≥ 5.7:1;
- тап-цели: чекбокс задачи и точка синхронизации — 44×44 при сохранении визуального размера;
- шторка: доступное имя (`aria-labelledby`), `inert` на фоне, focus-trap, Escape, возврат фокуса;
- фокус не теряется при перерисовке списка (сохраняется по `data-fkey`);
- live-регион для смены дня, выполнения задачи, отметки привычки и статуса синхронизации;
- табы: `Home`/`End`, фокус переходит в панель, навигация идёт до контента в DOM;
- приоритет задачи виден не только цветом, но и текстом;
- `color-scheme` для нативных контролов, `prefers-reduced-motion` учитывается и в JS.

Что осталось: настоящий прогон VoiceOver на iPhone (аудит — это код и замеры, не скринридер-тест),
радиогруппа для выбора приоритета, list-семантика для привычек и недели.

## Проверки, которые уже прогнаны

- Рендер всех пяти экранов в WebKit на 390×844 и 1200×900 — без ошибок JS.
- Цикл синхронизации против мока Supabase: отправка изменений, получение чужой
  правки дня, слияние по `updatedAt`, повторный рендер.
- Офлайн-загрузка: приложение открывается без сети, состояние читается из `localStorage`.
- Код-ревью: гонки в очереди синхронизации, переход через полночь, блоки вне сетки дня.
- Доступность: контраст, тап-цели, фокус в динамике, имя диалога, `inert` фона (проверено рантаймом).
